sqrt(animal)

Return the square root of an animal.

Parameters

animal : str
The animal to take the square root of.

Returns

result : str
The square root of animal.

Raises

ValueError
If animal has no known square root.

See Also

add : Add two animals together.

add(a, b)

Add two animals together.

Parameters

a : str
The first animal.
b : str
The second animal.

Returns

result : str
The combined animal.

Examples

GET /api/add?a=cat&b=dog

{"result": "cat-dog"}
